# Fotos del negocio

La galería tiene tres espacios reservados en index.html. Todavía no hay imágenes.

Cuando recibamos las fotos de Fumigaciones Claudio:

1. Revisá que correspondan a sus trabajos y que no expongan datos privados.
2. Guardalas dentro de esta carpeta con nombres claros, por ejemplo:
   - trabajo-01.webp
   - trabajo-02.webp
   - trabajo-03.webp
3. Corregí la orientación y optimizá el tamaño sin perder legibilidad.
4. Reemplazá cada bloque con data-photo-slot por una imagen local, con loading="lazy", decoding="async" y un alt descriptivo basado en lo que realmente se ve.
5. Conservá los espacios restantes si no hay suficientes fotos. No uses imágenes de stock como si fueran trabajos propios.
